# Data Visualization with Seaborn

This project demonstrates various data visualization techniques using the Seaborn library in Python. The dataset used in this project is about transformers and LSTM, sourced from the Seaborn data repository.

## Dataset

The dataset used in this project is labeled as `transformers.csv` and is assumed to be located in the specified folder path. The dataset contains information about different models, tasks, scores, and years.
![DatasetPic](https://dlmeqwbnyvguihvtcgat.supabase.co/storage/v1/object/public/eliteClub/dataset.png?t=2024-07-02T10%3A07%3A22.004Z)

## Visualizations

The following visualizations are created in this project:

1. **Distribution Plot**: Shows the overall distribution and central tendency of the Score values.
2. **Box Plot**: Compares the distribution of scores across different tasks.
3. **Bar Plot**: Identifies which models perform better on average.
4. **Point Plot**: Visualizes how scores have changed over time for different tasks.
5. **Heatmap**: Understands the relationships between different numerical variables in the dataset.
6. **Pair Plot**: Visualizes the relationships between pairs of numerical variables.

## Prerequisites

- Python 3.x
- Pandas
- Seaborn
- Matplotlib

## Installation

To install the required libraries, you can use pip:

```bash
pip install pandas seaborn matplotlib
```

## Usage

1. Clone the repository or download the code.
2. Ensure the dataset `transformers.csv` is located in the specified folder path.
3. Run the script to generate the visualizations.
